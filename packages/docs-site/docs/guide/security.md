# 安全与合规

Heurion 面向医疗机构设计,从架构上保证数据安全、可审计与合规。

## 产品定位

- Heurion 是**科研辅助工具**,不构成医疗器械
- **不提供诊断、治疗或预后判断**
- 所有 AI 输出仅供参考,须由执业医师审阅

## 数据安全

- **数据不出院**:支持本地化部署,敏感数据不离开院区
- **隔离架构**:科研计算与核心患者数据物理隔离,计算异常不影响病历
- **最小权限**:插件与自动化任务仅获得完成任务所需的最小访问范围
- **传输加密**:所有访问通过加密通道

## 可审计

- 每次访问、对话、文件生成与事实变更都被**不可变记录**
- 管理员操作可审计
- 支持完整数据导出(备份/合规删除)

## 法规映射

| 法规/框架 | Heurion 对应机制 |
|---|---|
| 个人信息保护法(PIPL) | 最小必要收集;数据本地化;用户导出与删除 |
| HIPAA | 租户隔离;不可变审计日志;角色访问控制;加密传输 |
| GDPR | 数据主体导出/删除;日志保留策略可配置;最小化处理 |
| 医疗数据分级分类 | 敏感字段按用途分级;科研沙箱与病历库隔离 |

## 用户控制

- 每个用户的数据按工作区**隔离存储**,互不可见
- 可在"设置"中管理账户
- 可随时导出或删除自己的数据
