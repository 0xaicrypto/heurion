# 患者管理

患者管理模块帮助医生沉淀患者全周期资料:建档、随访轨迹、影像、检验、报告与病历,并支持基于患者上下文的问诊对话。

## 患者列表

- 左侧导航进入 **患者**
- 新建患者:填写姓名缩写、年龄、性别与主诉
- 每个患者拥有独立空间,互不干扰

## 患者摘要

进入患者后默认展示**摘要**:基本信息、主诉、最近的关键事件。

复诊时的一句话:"唤起这位患者最近三年的随访轨迹" —— AI 会调出化验趋势、基因变异、影像结论,按时间轴排列。

## 患者对话

患者详情页内的"对话"会自动关联该患者的上下文:

- 年龄、性别、主诉等基础信息自动注入
- 相关检验、影像、报告参与讨论
- 回答内容尽量**溯源**:点击引用可查看原始记录
- 使用场景固定为"患者问诊"

## 影像与检验

- **影像**:上传影像文件(CT 等),AI 可协助解读要点
- **检验**:记录化验数据,查看趋势

## 报告与病历

- **报告**:为患者生成科研报告/随访总结,可导出
- **病历**:管理病历文档,支持上传与检索
- 底层数据变更后,依赖它的报告会自动标记**失效**,避免误用旧结论

## 记忆图谱

患者专属记忆图谱可视化:

- 事实(Facts):从对话与文档中提取的原子知识
- 知识(Articles):由事实组合的完整知识单元
- 点击节点可查看来源与更新时间

## 合规提醒

- 患者数据按用户隔离存储
- 科研计算与患者核心数据物理隔离
- 涉及诊断的表述严格遵循病历原文,不自行推断升级
