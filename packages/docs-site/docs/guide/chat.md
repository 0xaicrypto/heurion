# 对话

对话是 Heurion 的核心入口。这里介绍会话管理、场景选择、附件、技能与深度分析。

## 会话管理

- **新建会话**:点击"新建会话"创建,可命名以便区分任务
- **切换会话**:顶部会话列表,草稿按会话独立保存
- **关闭会话**:关闭后本地聊天记录清除(历史记忆仍在系统中)
- **重新生成 / 重试**:对失败或不满意的回复,可重新生成或重试

## 场景选择

每次对话前选择场景,AI 行为随之调整:

- **通用对话**:适合独立任务,如"解释这个概念""帮我检查这段文字"
- **患者问诊**:适合复诊与随访,AI 自动读取患者图谱,回答附溯源
- **文档写作**:在写作工作台中使用,AI 围绕当前文档工作
- **图表分析**:适合"画一张 KM 曲线""做两组比较"等请求

::: tip 提示
场景在会话中保持;患者对话页与文档编辑页会自动使用对应场景。
:::

## 附件与图片

- **上传文件**:回形针按钮上传,支持文档与图片
- **图片解读**:上传化验单/影像截图,AI 直接解读内容并结构化;
  若当前模型不支持图片,系统明确提示,可用 OCR 工具或切换视觉模型
- **附件上下文**:文件内容会注入对话,可针对文件提问(如"这份报告有哪些异常指标?")

## 技能

技能是可复用的工作流,例如固定的随访模板、报告格式。

- 在输入区上方的技能栏启用/停用
- 启用后 AI 会遵循技能描述完成任务
- 在"技能"页面可管理已保存的技能

## 深度分析

对复杂问题可发起"并行深度分析":

1. 点击输入区旁的深度分析入口
2. 选择分析主题(文献/临床等)
3. 系统并行开展多路分析,汇总结果

## 诚实原则

- AI **不会编造数据**:数据缺失时明确说明并询问
- 每个结论尽量**可溯源**:点击引用查看原始记录
- 涉及患者信息时,仅引用患者图谱中已有的内容
