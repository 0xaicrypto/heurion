# 快速开始

## 注册与登录

1. 打开 [heurion.org](https://heurion.org),点击右上角"免费开始使用"
2. 使用邮箱注册并完成验证
3. 登录后进入工作台("今日"页面),可看到待办与最近动态

## 第一次对话

1. 左侧导航进入 **对话**
2. 点击"新建会话",输入会话名称
3. 在输入框上方选择对话场景(见下方说明)
4. 输入问题并发送,例如:"总结这份出院小结的关键信息"

**新手建议**:从"通用对话"开始,熟悉后按任务切换场景。

## 对话场景

| 场景 | 适用场景 | 行为差异 |
|---|---|---|
| 通用对话 | 独立任务、通用问题 | 不预设患者上下文,专注完成当前请求 |
| 患者问诊 | 复诊、随访、病历讨论 | 自动关联患者图谱与记忆,回答有据可查 |
| 文档写作 | 起草/修改文档 | 围绕当前文档,支持直接改写 |
| 图表分析 | 统计图表、数据可视化 | 优先图表工具;数据缺失时明确告知,绝不编造 |

## 上传资料

- 点击输入框旁的**回形针**上传文件
- 支持:病历文档(PDF/Word/文本)、化验单、影像截图等
- **图片**:可直接被解读(化验单、报告照片);若模型不支持图片,系统会提示使用 OCR
- 上传的文件会作为对话附件参与分析
