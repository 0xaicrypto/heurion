# 记忆与知识库

Heurion 的核心能力之一:AI 拥有持久、可溯源、可失效传播的临床记忆。

## 记忆如何工作

每次对话、每份上传文档,系统都会沉淀为记忆:

- **事实(Facts)**:从对话与文档中提取的原子知识(化验结果、诊断、偏好等)
- **知识(Articles)**:由事实组合的完整知识单元(患者总结、研究结论)
- **摘要(Episodes)**:一段会话的浓缩摘要

记忆按重要性与时效性加权,回答时自动注入最相关内容。

## 溯源

- 每个结论都可**点击追溯**到具体日期的原始记录
- 记忆图谱中点击节点,查看来源与更新时间
- AI 引用患者信息时,仅引用图谱中已有的内容,**不会编造**

## 失效传播

底层数据变更后:

- 依赖该数据的上层报告自动标记 **Stale(失效)**
- 避免"旧结论配新数据"的误用
- 更新底层数据后,报告可重新生成

## 知识库

- **知识文章**:保存研究进展、指南要点、团队经验
- **检索**:自然语言检索知识库
- **知识命令**:如"搜索知识库中关于 XX 的内容""总结知识库缺口"
- AI 主动识别数据缺口(Gaps)并提问,而非强行作答

## 审核待审文章的检查清单(#813)

AI 合成的知识文章进入待审队列后,批准前请核对:

- [ ] **结论**:是否有明确的核心结论(而非事实罗列)
- [ ] **依据**:每条依据是否标注了来源事实(ID 与置信度),点击可回溯
- [ ] **注意事项**:不确定性、适用边界、证据冲突是否被如实列出
- [ ] **无编造**:结论中没有出现依据里不存在的事实
- [ ] **时效**:文章下方若出现"⚠️ 已过时(某事实已修订/删除)"标注,
      请先确认底层数据后再决定"重新生成"或"拒绝"

已过时的文章在对话注入时会自动带失效标注;重新生成会按最新的
来源事实重建"结论/依据/注意事项"结构。

## 记忆图谱

全局视图查看记忆网络:

- 节点:患者、事实、知识、文档
- 连线:依赖与引用关系
- 颜色标注状态(有效/失效/低置信)

## 管理记忆

- 在"记忆"页面查看事实列表与置信度
- 可删除错误提取的事实
- 数据导出功能支持完整导出(合规)
