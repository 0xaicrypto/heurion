# 研究与写作

面向研究人员的完整工作流:研究项目管理、写作工作台、统计图表与投稿。

## 研究管理

- 左侧导航进入 **研究**
- 创建研究项目,登记方案与随访计划
- 研究详情页:查看数据、生成图表、组织协作
- 系统记住研究短码,提及研究时自动关联

## 写作工作台

- 创建文档:临床总结、综述、研究报告
- 富文本编辑:标题、表格、图片、引用
- **随对话修改**:在文档旁的对话中提出修改要求,AI 直接改写文档
- 文档引用参考文献,可溯源

## 统计图表

在图表场景或写作工作台可生成:

- **Table 1**(基线特征表)
- **KM 生存曲线**
- 组间比较(卡方检验等),标注方法学与样本量
- 学术 PPT / DOCX 导出

::: warning 诚实原则
数据缺失时,AI 会明确说明并索要真实数据,**不会用占位值冒充结果**。生成图表请核对样本量与统计方法。
:::

## 方案查看与投稿

- **方案查看器**:只读预览研究方案
- **投稿**:期刊投稿流程与格式检查

## 工作流示例

1. 随访数据录入 → 患者列表与检验趋势
2. 一句话:"清洗随访数据并生成 Table 1"
3. 一句话:"画两组生存分析 KM 曲线"
4. 导出学术 PPT,引用全部可溯源
