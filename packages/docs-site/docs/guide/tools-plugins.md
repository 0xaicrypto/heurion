# 技能与插件

通过技能与插件扩展 Heurion 的能力,按需启用,保持核心轻量。

## 技能

技能是可复用的工作流描述,让 AI 按固定方式完成任务。

**使用**:

1. 对话输入区上方的技能栏,点击启用/停用
2. 启用后,AI 遵循技能描述处理当前对话
3. 常用场景:固定的随访模板、报告格式、分析流程

**示例**:"随访总结模板"技能启用后,每次生成的随访总结都遵循统一结构。

## 插件

插件提供独立能力,在"插件"页面安装与启用:

| 插件 | 能力 |
|---|---|
| chart | 统计图表(柱状图、KM 曲线等) |
| bioscene | 3D 生物场景渲染 |
| browser-agent | 网页操作自动化 |

**安装**:

1. 进入 **插件** 页面
2. 浏览市场或输入插件标识安装
3. 在插件设置中配置
4. 启用后,对应工具自动出现在对话工具列表中

::: tip 提示
未安装插件时,相关图表能力在对话中会明确提示安装,不会静默缺失。
:::

## 文件与日程

- **文件**:管理上传的资料,支持检索与复用
- **日程**:登记随访与任务提醒

## 数据导出

- **导出**:完整导出你的数据(对话、记忆、文件)
- 用于备份或合规删除
