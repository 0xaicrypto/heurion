# Heurion 用户使用指南

欢迎使用 Heurion —— 面向临床科研的数字化医疗助手。

Heurion 帮助你管理患者随访、沉淀临床记忆、完成科研写作与统计图表,并让 AI 真正"动手":清洗数据、生成报告、操作网页。

::: tip 重要声明
Heurion 是科研辅助工具,**不提供诊断或治疗决策建议**。所有 AI 输出必须由执业医师审阅确认。
:::

## 快速上手

1. **注册并登录** — 在 [heurion.org](https://heurion.org) 注册账户
2. **创建会话** — 进入"对话",新建会话并选择场景
3. **开始提问** — 直接输入问题,或上传病历、化验单、影像图片
4. **探索功能** — 从左侧导航进入患者、研究、写作、记忆等模块

## 核心能力一览

| 能力 | 说明 |
|---|---|
| 场景化对话 | 通用 / 患者问诊 / 文档写作 / 图表分析 四个入口 |
| 图片解读 | 上传化验单、影像截图,AI 直接解读(或 OCR) |
| 临床记忆 | 患者图谱、事实溯源、失效自动标记 |
| 研究与写作 | 研究管理、文档创作、统计图表、投稿 |
| 插件扩展 | 图表、生物场景、网页操作按需安装 |
| 本地化部署 | 数据不出院,支持院内私有化 |
