# Heurion 临床 AI 工作站

> **让每一次问诊、每一份文件、每一次确认，都沉淀为可审计、可进化、可导出的临床记忆。**

---

## 一句话定位

Heurion 是面向肿瘤研究与临床团队的**自我进化 AI 工作站**。它把碎片化的对话、病历和文件提炼成结构化的统一记忆图，自动提取事实、合成知识、标记未知问题，并在后续问诊和报告中自动调用——让 AI 真正“记得”患者与团队的知识，随你一起成长。

---

## 面向谁

- **肿瘤临床研究者**：管理入组患者、研究方案、随访数据与不良反应。
- **临床医生 / MDT 团队**：需要长期追踪患者背景、减少重复询问、降低决策幻觉。
- **医学科研助理**：快速生成病例总结、学术 PPT、Table 1 与统计图表。
- **医院 / 科室 IT**：希望 AI 数据可解释、可审计、可本地部署。

## 临床 AI 的三大痛点

| 痛点 | 传统聊天机器人 | 代价 |
|---|---|---|
| **无状态** | 每次对话后“失忆”，医生反复提供背景 | 时间浪费、体验差 |
| **不可审计** | AI 的结论从哪来、依据是否过期，无法追溯 | 医疗风险、合规隐患 |
| **知识与工作流割裂** | 病历、聊天、报告各管一段，无法沉淀复用 | 重复劳动、信息孤岛 |

## 系统架构：从输入到记忆的闭环

```
临床输入        事件日志        进化引擎          统一记忆图         智能输出
问诊 / 文件 / 病历  →  不可变、可审计  →  提取·链接·合成  →  Facts / Articles / Gaps  →  检索 / 报告 / 决策
```

**关键设计**：所有临床输入先写入不可变事件日志（EventLog），再由异步进化引擎提炼成统一记忆图；医生的每次确认或编辑都会回到事件日志，驱动记忆持续进化。这让 Heurion 区别于普通聊天机器人：它不只是“回答问题”，而是把团队的知识沉淀成可审计、可复用的资产。

## 三大核心能力

### 1. 统一记忆图（Memory Graph）

把 Facts、Articles、Gaps、Skills、Entities、Documents 视为同一张图谱的节点，用关系（依赖、派生、替代、回答）连接起来。

- **版本化**：Fact / Article 每次编辑都产生新版本，旧版本保留，可追溯。
- **影响分析**：修改一个 Fact，自动看到会影响哪些 Article。
- **患者子图**：按患者一键聚焦相关节点，辅助 MDT 决策。
- **可导出**：支持 `.hma`（Heurion Memory Archive）完整归档。

### 2. 可进化知识库（Evolving Knowledge Base）

知识不是一次性配置，而是在使用中自动生长、自动修正。

- **自动提取**：从聊天与文件中抽取结构化 Facts。
- **自动合成**：同一主题积累足够 Facts 后生成 Article。
- **自动失效传播**：底层 Fact 变化时，依赖它的 Article 自动标记为 stale，并可一键重新生成。
- **Knowledge Gap**：系统把“我不知道”显式化，等待回答或验证，避免幻觉。

### 3. 智能报告助手（Smart Report Assistant）

一句话把临床讨论变成可交付文档，且不阻塞聊天流。

- 生成 DOCX（病例总结、随访记录）、PPTX（学术汇报）、表格（Table 1、AE 汇总）、图表（KM 曲线、森林图）。
- 文件链接持久化，刷新不丢。
- 生成内容可一键加入知识库，形成“报告 → 事实 → 文章”的闭环。

## 典型使用场景

**患者长期管理**  
一位肺癌患者历次 CT、病理、用药记录被沉淀为 Facts；当医生问“下一步治疗”时，系统自动召回患者子图，避免给出脱离病史的通用建议。

**研究方案撰写**  
研究团队上传试验方案、入组标准与文献，系统自动提取关键事实并合成 Article；需要汇报时，一句话生成学术 PPT 与 Table 1。

**知识维护与审计**  
医学经理修改一条 Fact，系统立即提示将影响 3 篇 Article；确认后 Article 自动标记 stale，并可一键重新生成，确保对外内容始终一致。

## 安全与合规

- **租户隔离**：每个用户的事件日志、事实、知识与文件独立存储。
- **双平面隔离**：控制面（认证、患者、知识库）与执行面（报告渲染、插件沙箱）分离。
- **可审计**：不可变 EventLog 记录每次聊天、文件生成与事实变更，支持导出。
- **自托管友好**：Docker Compose 一键部署，API 密钥与数据库连接可通过环境变量配置，数据不出境。
